# 📚 Journal Metrics & Quartile Lookup Tool

Automated Google Colab tool to look up SCImago Journal Quartiles (Q1–Q4), SJR Scores, and 2-Year Impact Factor equivalents from journal names, ISSNs, or citation files (`.ris` / `.bib`).

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/saifulbutex/journal-quartile-checking/blob/main/Quartile_checking.ipynb)

---

## 🚀 Features

- **Single Lookup:** Search any journal instantly by Name or ISSN.
- **Batch Processing:** Upload `.ris` or `.bib` files to process all citations at once.
- **Automatic Export:** Downloads an updated, styled Excel sheet with resolved metrics.
- **Fast & Cached:** Loads SCImago data into memory to prevent repeated downloads.

---

## 🛠️ How to Use

1. Click the **Open in Colab** badge above.
2. Choose your input mode from the form dropdown:
   - **Option 1:** Enter a single Journal Name or ISSN.
   - **Option 2:** Upload your `.ris` or `.bib` citations file.
3. Click the **Play (▶)** button on the cell to run.
4. Download your processed Excel file automatically when complete.
